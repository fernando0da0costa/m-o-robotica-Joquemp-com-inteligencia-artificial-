Calibração dos servos

180° (posicional): cada valor é o ângulo final do dedo (0–180°). 360° (rotação contínua): cada valor é um tempo de pulso em milissegundos — o servo gira até bater no batente mecânico e para; "V. abrir"/"V. fechar" definem o sentido de giro e "Parado" o valor que não gira (ajuste fino, gira em torno de 90). A mão sempre começa e passa pela posição aberta antes de um gesto novo. Use os botões "Testar" para mover só aquele servo e conferir. Os valores ficam salvos no navegador (localStorage) e continuam disponíveis mesmo depois de fechar a página.

Requisitos

  • Navegador Chrome, Edge ou Opera no desktop (Web Serial API não funciona no Firefox/Safari).
  • Página servida via http://localhost (ex.: python3 -m http.server) ou https:// — abrir o arquivo direto (file://) pode não funcionar.
  • Arduino Uno com o firmware rps_hand_firmware.ino gravado, conectado por USB.
  • 5 servos SG90 alimentados por fonte externa 5V, com GND comum com o Arduino — ver PLANEJAMENTO.md.

Como usar

  1. Clique em "Conectar Arduino" e escolha a porta serial.
  2. Clique em "Iniciar câmera" e permita o acesso.
  3. Na aba Calibração, ajuste o tempo de pulso (ms) de cada dedo até a mão abrir/fechar certo.
  4. Mostre pedra, papel ou tesoura para a câmera — a mão robótica reproduz o gesto, sempre passando pela posição zero.

Projeto estático — sem backend. Parâmetros salvos localmente no navegador.
